## Описание проекта
Интерактивная 3D-симуляция полёта сквозь звёздное поле.
Звёзды появляются в произвольных точках пространства и движутся
от центра экрана к краям, создавая эффект движения наблюдателя
вперёд сквозь космос.

### Реализованные возможности
- 3D-перспективная проекция: размер и яркость звёзд зависят
  от расстояния до наблюдателя
- Три цвета звёзд: белый, голубой, оранжевый
- Следы (trails) у приближающихся звёзд
- Регулировка скорости полёта с клавиатуры (W / S)
- Управление направлением полёта мышью
